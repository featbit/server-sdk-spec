# Shared Conformance Fixtures

This directory is reserved for language-neutral client SDK fixtures. No executable shared fixture suite is included in this draft.

Future fixtures should be versioned with the specification and consumed through each SDK's native test framework. Cover user changes, full/patch ordering, cache and bootstrap eligibility, conversion, notifications, and event behavior. Server-side targeting and rollout vectors are outside the client evaluation model.

See the [acceptance checklist](../spec/conformance.md) and [protocol examples](../reference/protocol.md) for the initial scenarios and payload shapes.
